# Математика денойзера
В ТЗ предлагается обучение денойзера, а также обучение денойзера через интерполянт, ака векторного поля FM.
Базовые задачи на проект являются :

- Абляция многообразия хидденов.
- Абляция векторного поля.

Поэтому я решил для начала работать с обычным денойзером. Так как обучение на всех уровнях шума может давать денойзеру слишком много информации (дальше будет понятнее).

Обучение строится на денойзере $f : h + \xi \rightarrow h$, что при обучении в L2 можно свести к условному матожиданию. 

$$\mathbb{E} [h | h + \xi], \quad \xi \sim \mathcal{N} (0, \sigma^2)$$

Из этого можно получить скор-функцию векторного поля, применив формулу Твиди.

$$\mathbb{E} [h | h + \xi] = h + \xi + \sigma^2 \nabla \log p(h+\xi), \quad p \sim p_h * p_{\mathcal{N}(0, \sigma^2)}$$

Что при небольших sigma может давать хорошую аппроксимацию многообразия обычных состояний хиддена.

Из этого можно получить несколько интересных идей для стиринга. 

(i) Сделав предоположение о том, что во время дивжения по направления вектора DoM, нам требуется также двигать хидден и по другим направлениям, и что очень важно делать это непрерывно. Необходимость изменения по другим координатам звучит очевидно, если принять за правду Linear Representation Hypothesis и практические проблемы с деградацией "стандартного" стиринга, но то что это изменение должно быть непрерывным неочевидно и требует дополнительных экспериментов.

Так можно записать новый формат стиринга :

$$\mathrm{d} h = (\alpha v + f(h))\mathrm{d} t$$

И предположить, что $f(h) = \sigma^2 \nabla \log p(h)$

(ii) Можно предположить, что после стиринга, рядом будет "островок" многообразия на который можно будет проецироваться. Зная скор-функцию плотности, что и делает стандартный денойзер.

### Коэффициент скор-функции
Дополнительным гиперпараметром к этим экспериментам может послужить коэффициент у скор-функции помимо $\sigma^2$.

# Обучение Денойзера
Для выбора архитектуры нужно учесть, что хиддены находяться в суперпозиции, иными словами в "сжатом латентном пространстве", а шум будет нести меньше степенй свободы чем хиддены, для этого может понадобиться SAE-like стркутра которая позволит делать операции с хидденами проще. А также U-Net архитектуры с боттлнеком не будут подходить, тк нет смысла искать латентную информацию.

Для этого я прогнал несколько вариаций Residual-MLP, c Drouput p = 0 и 0.1, с блоками, вида, для нескольких уровней шума. Обучение шло также на OpenWebText.
```

```

# Ablation векторных полей
После обучения денойзера, хочется понять насколько хорошо денойзер знаком с реальными данными после стиринга и понимает в каком направлении двигаться. А также могла ли такая точка попасть в обучаемый датасет. Иными словами провести :
- Epistemic uncertanity analysis
- Out-Of-Distribution analysis

И если для коэффициентов стиринга, $\alpha \le 5$. Вектор стринга натурально попадает в область (просто посчитав персентиль отколнения гауссовского шума). То для больших $\alpha$ точка может покрываться денойзером, только в том случае, если при стиринге находиться соседний "островок", в который можно заденойзиться, ну или шагнуть по скор-функции. Что может оправдать (ii) гиптоезу.

Епистемик удобно определять наличием неопределенности у ансамбля - высокая дисперсия выходов будет означать что модель не знает что выдавать для таких параметров, а сам ансамбль удобно симулировать дропаутом на инференсе на чем и был основан этот эксперимент.

Важно учитывать, что высокий стиринг будет повышать маштаб MLP слоя, поэтому для оценки епистемика лучше использовать SNR.

## Steering Aligment
Построив графики длин проекции векотра скор-функции и его ортогональной составляющей стиринг вектору, видно что при денойзинге, при большем шуме, вектор скор-функции сильнее отменяет направление стиринга, и сильнее стремиться к центру распределения, когда меньший шум ищет другие ближайшие "островки". Однако маленький шум страдает быстрым затуханием плотности, что отражается большой длиной вектора градиента.
![](steering_projection_removal.png)
![](score_orthogonal_norm.png)

Общий вывод из аблейшина Денойзера :
- Маленький шум не страдает от OOD данных, и лучше ищет локальные направления для денойзинга.
