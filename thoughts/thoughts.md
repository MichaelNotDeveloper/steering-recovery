# What task are we solving?
Для начала какой стиринг мы хотим делать.

- Residual Stream, block 6
- Intervention at every generation step (учитывая последний токен промпта)
- Steering vector : $h \leftarrow h + \alpha (\mu_+ - \mu_-)$


Общее тз предлагает прямой подход, делать стиринг, да так чтобы не портить выходы модели. И у этого есть одно базовое решение.
```
1. Делаем стиринг по вектору 
2. Редактируем отображение в обычный вид
```
Уже есть готовый подход через generative latent prior. 
У этого есть несколько проблем, помимо медленной скорости (можно попробовать ускорить через Flow Maps)
1. Теоретическое обоснование оторбражения, это просто : "возвращает к нужному распределению".
2. Нету регуляризции на длину вектора, теоретически модель может после стирирнга просто вычесть вектор $\alpha v$ тем самым отменив стирирнг, но вернув распределение хиддена в нужную позицию.
3. Нету сравнения "кол-во шагов" -> "метрика", есть только "кол-во шагов" -> FID

# Denoiser approach
Подходим к задаче дейнойзера через MLP $f : h + \xi \rightarrow h$ и обучаемся на L2 Loss (базовый вариант без интерполянта)
$$
\|f(h + \xi) - h\|^2, \quad \xi \sim \mathcal N(0, \sigma^2)
$$
Пользуясь курсом теорвера и диффузионок можем заменить MLP на уматож, что по формуле Твиди можно свести к 
$$
f = \mathbb E [h | h + \xi] = h + \sigma^2 \nabla \log p_{h \circ \sigma} (h)
$$
Что в случае стирирнга будет делать один градиентый подъем по плоности полученной через свертку (что сильно напоминает один шаг Ланжевена), через эту свертку также можно достать и сам лог градиента
- Тот факт что мы получаем не оригинальную плотность а плотность свертки может служить регуляризатором для эсперимента


## Interpolant denoiser is actually a flexible FM.
В ТЗ самой задачи предлагается учить денойзер через интерполянт. (ака обучение векторного поля, что буквально делает статья GLP.)
$$
h_t = t h + (1 - t) \xi, \quad \xi \sim \mathcal{N}(0, I)
$$
Также применяя Твиди получаем похожий результат сo скорфункцей.
$$
f(h_t) = \frac{h_t + (1 - t)^2 \nabla \log p_t (h_t)}{t}, \quad p_t = p_h * \mathcal N (0, (1 - t)^2)
$$

- Причем, ссылаясь на [блогпост](https://arc.net/l/quote/bihexkmj), можем предполагать что добавление входного параметра $t$ можеет быть не обязательным в связи отсуствия пересечений в траекториях даже при проекции всех времен на одну плоскость.

Однако GLP не было проверено, что менеьшее кол-во шагов по векторному полю могут также хорошо работать.
